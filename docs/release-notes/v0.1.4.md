# DeepSeek Harness Desktop v0.1.4

**摘要 / Summary:** 修复桌面版插件市场「立即重启」：插件更新后，重启请求现在由拥有 dsh 子进程的桌面宿主执行，并自动切换到新服务地址。

## 修复 / Fixes
- **插件市场「立即重启」无效**：桌面版不再让 dshmarket 自行终止并派生 dsh 进程。市场发出的同源 `POST /dsh-market/restart` 会委托给 Tauri 的现有重启命令；宿主停止受管子进程、启动替代服务，并在收到新 URL 后让 WebView 跳转。
- 重启桥仅处理当前页面同源的指定 POST 请求；普通浏览器中的 dshmarket 和其他 fetch 请求保持原有行为。

## 安装与更新 / Install & Update
- 现有用户可在应用内更新面板安装 v0.1.4；插件更新后点击「立即重启」即可加载需要重启的变更。
- macOS 包未公证：首次打开需在「系统设置 → 隐私与安全性」中允许。
