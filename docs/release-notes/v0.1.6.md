# DeepSeek Harness Desktop v0.1.6

**摘要 / Summary:** 修复 v0.1.5 发布流水线中缺失的 dshmarket 版本固定值。原生安装包继续内置 Node.js 24 和 npm，Gitea 收到发布标签后自动创建镜像安装包。

## 修复 / Fixes
- **发布打包**：恢复 dshmarket `1.11.3` 的固定版本，避免 CI 把空版本解释为最新 dshmarket 后导致下游补丁锚点不匹配。

## 安装与更新 / Install & Update
- Windows、macOS 和 Linux 原生安装包包含匹配平台的 Node.js 24、npm 和 dsh；无需用户预装 Node.js/npm。
- Gitea pull mirror 收到 `v*` 标签后会等待 GitHub Release 安装包完成，再自动创建 Gitea Release 与应用内更新 feed。
