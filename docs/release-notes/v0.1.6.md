# DeepSeek Harness Desktop v0.1.6

**摘要 / Summary:** 修复 v0.1.5 发布流水线中缺失的 dshmarket 版本固定值。原生安装包继续内置 Node.js 24 和 npm；Windows 首次部署现在显示进度、保持桌面壳内运行，不再额外弹出 PowerShell 或浏览器。

## 修复 / Fixes
- **发布打包**：恢复 dshmarket `1.11.3` 的固定版本，避免 CI 把空版本解释为最新 dshmarket 后导致下游补丁锚点不匹配。
- **Windows 原生启动**：内置 dsh 改为由桌面壳直接执行内置 `node.exe` 与 JavaScript 入口，不再经过 `.cmd` 命令解释器；子进程不创建控制台窗口，且添加 `--no-open` 防止自动打开浏览器。
- **首次部署反馈**：启动页显示 Node.js/npm、DeepSeek Harness 和 web 服务三个阶段的确定进度，首次部署不再静默等待。
- **无边框窗口拖动**：自定义标题栏拖动区显式调用原生窗口拖动接口，恢复 Windows 拖动窗口能力。

## 安装与更新 / Install & Update
- Windows、macOS 和 Linux 原生安装包包含匹配平台的 Node.js 24、npm 和 dsh；无需用户预装 Node.js/npm。
- Gitea pull mirror 收到 `v*` 标签后会等待 GitHub Release 安装包完成，再自动创建 Gitea Release 与应用内更新 feed。
