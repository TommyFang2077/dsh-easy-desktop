# DeepSeek Harness Desktop v0.1.7

**摘要 / Summary:** 强化 Windows 的运行时部署、启动故障证据和安装包发布校验；无需系统 Node.js/npm 的自包含启动方式保持不变。

## 修复 / Fixes
- **可恢复运行时部署**：内置 Node.js 与 dsh 切换时保留上一份完整目录；若激活失败会恢复可用版本，避免中断部署留下不可启动状态。
- **Windows 捆绑件加载**：继续将 ModLens、dshmarket 与 dsh-desktop-voice 实体化到用户 profile，避免普通用户目录符号链接权限导致加载失败。
- **启动故障证据**：保留 dsh 服务输出，并记录 Node.js、dsh、捆绑件部署和服务就绪阶段；异常退出会在下次启动标记。

## 发布 / Release
- **Windows CI**：在 `windows-latest` 上执行 dsh-core 回归测试，覆盖 Windows 运行时、路径和捆绑件分支。
- **安装包 gate**：发布前验证 NSIS `.exe` 和 MSI 产物存在、非空且具有正确文件签名，阻止错误或缺失的 Windows 安装包进入 Release。

## 诊断 / Diagnostics
- Windows 启动失败时可检查系统数据目录中的 `dsh-desktop/logs/dsh-desktop.log` 与 `dsh-desktop/diagnostics/startup.jsonl`；提交 issue 前请先检查日志内容。
