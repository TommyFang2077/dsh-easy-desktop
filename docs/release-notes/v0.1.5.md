# DeepSeek Harness Desktop v0.1.5

**摘要 / Summary:** 原生安装包现在内置 Node.js 24 和 npm；Windows 用户无需预装 Node.js/npm。Gitea 镜像在同步 `v*` 标签后自动等待 GitHub 安装包完成并创建对应发行版。

## 新增 / Added
- **内置 Node.js/npm runtime**：Windows、macOS 和 Linux 原生安装包随 dsh 一起携带匹配平台的官方 Node.js 24 与 npm。首次启动自动部署到应用数据目录；后续仅在内置 Node 版本变化时更新。
- **Windows 自包含启动器**：`dsh.cmd` 直接调用应用部署的 `node.exe`，不依赖系统 PATH 或用户安装的 Node.js。
- **Gitea 自动发布**：Gitea pull mirror 收到 `v*` 标签后自动等待 GitHub Release 的完整安装包，再创建 Gitea Release、上传可镜像的安装包并更新应用内更新 feed。

## 改进 / Improvements
- dsh 在线检查和更新优先使用内置 npm，默认仍使用 `https://registry.npmmirror.com`。
- Node runtime 下载在构建时按官方 SHA-256 清单校验，且随发布目标选择正确 CPU 架构。

## 安装与更新 / Install & Update
- Windows 用户只需安装 WebView2；Node.js/npm 不再是前置条件。
- 已安装的桌面版会在下一次启动时自动部署内置 runtime；离线时继续使用安装包内的 dsh。
