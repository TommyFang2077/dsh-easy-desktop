# DeepSeek Harness Desktop v0.1.3

**摘要 / Summary:** v0.1.3 增量重发：所有安装包内置官方 dsh 并支持在线更新；修复损坏插件记录导致服务 exit 1、市场更新被回退、Release 资产错发版本与 Gitea 上传假失败。

## 新功能 / Features
- **内置官方 dsh 内核**：Windows、macOS、deb/rpm 与 Flatpak 均随包提供 `@deepseek-ai/dsh 0.1.0-rc.7`，首次启动先复制到应用更新目录，不再联网下载内核
  - 非 Flatpak 仍需要本机 Node.js 运行官方内核；有 npm 时每天检查官方内核在线更新
  - `DSH_DESKTOP_DSH_BIN` / `--dsh`、`--no-update` / `DSH_DESKTOP_NO_UPDATE` 的优先级与原有行为不变

## 修复 / Fixes
- **插件操作失败后软件无法启动**：启动前清理指向缺失包的社区 bundle 记录；服务 stderr 也会显示在错误详情，不再只有 `exit 1`
- **软件内插件更新被回退**：保留高于捆绑版本的 ModLens 与 dshmarket；捆绑市场更新到 1.11.3
- **GitHub Release 资产发到旧版本**：Tauri 版本同步为 0.1.3，Release 工作流增加 Cargo/Tauri 版本一致性门禁
- **Gitea 发布上传失败**：网关超时后检查已落盘的不可变包或 Release 资产；开发元数据从捆绑运行时移除以缩小安装包，超过镜像网关限制的 AppImage 改用 GitHub 签名下载地址
- **Windows 上 npx 缓存里的 dsh 无法启动**：优先使用 `dsh.cmd` shim
- **跨平台安装包构建失败**：将 dsh、ModLens 与市场依赖树压缩为单文件资源，避开 Windows 安装器路径上限；Flatpak 构建同步补齐资源占位文件

## 安装与更新 / Install & Update
- 安装包：Windows NSIS/MSI、macOS DMG（Apple Silicon 与 Intel）、Linux deb/rpm、Flatpak，均内置官方 dsh
- 非 Flatpak：本机 Node.js 负责运行内核；npm 可用时自动检查官方内核更新
- macOS 包未公证：首次打开需在「系统设置 → 隐私与安全性」中允许
- 壳更新提示出现在启动页：点击「下载并安装」后优先从 Gitea 镜像下载并校验 Tauri 签名；超过镜像网关限制的 Linux AppImage 使用 GitHub 下载地址
- 这是同版本号增量重发；已安装早期 v0.1.3 的设备不会把相同 SemVer 判定为新版本，需要手动重新下载安装包
